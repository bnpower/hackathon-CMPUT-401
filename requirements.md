# Hackathon Problem
 Create a job application manager, that helps job seekers track, apply, and manage their job applications.


# Tech Stack
Full stack web app inside a Docker container using wsl/ubunto. this will have seperate frontend and backend applications.

## Front End
front end should use Node React


## Backend 
Django - Python
### Backend Requirements 
Key Features to Implement:

Tracking Applications:

Ability to record and organize job applications with relevant details (company name, position, date applied, status).

Features to categorize applications by stage (e.g., applied, interview, offer, rejection).

Notifications or reminders for follow-up actions.

Master Resume Management:

Store a "master" resume template that can be quickly accessed and modified.

Allow users to create tailored resumes for different job applications by making quick edits to the master version.

Response Tracking:

Monitor responses from companies, including interview invitations, rejections, or job offers.

Log communications with potential employers.

Ease of Use & Accessibility:

Intuitive and simple user interface to help users navigate without complexity.

Accessible on both desktop and mobile devices, ensuring it can be used on the go.

Visual Design & Creativity:

Incorporate a visually appealing design that enhances the user experience.

Use creative design elements to make the process of managing job applications more engaging and motivating.
